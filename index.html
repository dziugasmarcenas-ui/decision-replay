    What this demonstrates

    One identity, unlike sources. Different field names and part aliases normalize to a shared event history. Raw identifiers remain attached.

    Decisions have a basis. Each proposal captures the rule version and evidence IDs. A human action is a separate record.

    A correction adds history. A later finding changes current eligibility without rewriting earlier proposals. Scrub backward to see the difference.
